Leonida Legend is an offline guide and tracker for all 55 PlayStation 5
trophies of Grand Theft Auto VI: 1 platinum, 2 gold, 6 silver and 46 bronze,
28 of them hidden on PlayStation until earned. Every trophy is shown with its
official name, description and grade as PlayStation publishes them, plus a
guide written in our own words that names its sources, a 6-stage roadmap to
the platinum, and a flag on each of the 18 missable trophies.

The tracker is a checklist saved in your browser (localStorage) with
export/import, filters by kind and grade, search, and a spoiler setting that
hides hidden trophies until you earn them. It is plain static files under
`app/` — no build step, no network requests at run time — so it works with the
network off.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in your browser.
